# 🎲 Dice Roll Project

A simple and interactive dice rolling web application built with **HTML, CSS, and JavaScript**.

The project allows users to roll two dice, generates random results for each die, and displays the combined total. It was created as an early web development project to practice JavaScript fundamentals, DOM manipulation, events, animations, and working with static assets.

## 🌐 Live Demo

**[Roll the Dice](https://rahul-khatavkar.github.io/Dice-Roll-Project/)**

---

## 📌 About the Project

The Dice Roll Project is a browser-based game where users can roll two dice and test their luck.

Each time the **ROLL THE DICE** button is pressed:

1. Both dice perform a short rolling animation.
2. A random value from 1 to 6 is generated for each die.
3. The corresponding dice images are displayed.
4. The values of both dice are added together.
5. The final result is displayed on the screen.

The project focuses on keeping the game simple while providing a clean and interactive user experience.

## ✨ Features

- 🎲 Two interactive dice
- 🔢 Random dice values from 1 to 6
- ➕ Automatically calculates the total of both dice
- 🔄 Dice rolling animation
- 🖼️ Dynamic dice images
- 🖱️ Interactive roll button
- 📱 Responsive layout for smaller screens
- 🎨 Custom yellow and orange gradient design
- ⚡ Runs completely in the browser
- 🚫 No backend or database required

- **HTML5** — Structure and content
- **CSS3** — Styling, layout, responsiveness, and animations

## 🎮 How to Play

1. Open the [Live Demo](https://rahul-khatavkar.github.io/Dice-Roll-Project/).
2. Two dice will be displayed.
3. Click **ROLL THE DICE**.
4. Wait for the dice animation to finish.
5. The dice will display randomly generated values.
6. The total of both dice will appear below them.
7. Roll again and try your luck!

The possible total ranges from **2 to 12**.
